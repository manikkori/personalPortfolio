# Manik — Personal Portfolio

> MERN Stack Developer portfolio built with vanilla HTML, CSS & JavaScript + GSAP animations.

![Portfolio Preview](./assets/img/hero2.jpeg)

---

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **JavaScript (Vanilla)** — DOM manipulation, IntersectionObserver, form handling
- **GSAP + ScrollTrigger** — Hero entrance, scroll parallax, stagger animations
- **Font Awesome + Simple Icons** — Skill & UI icons
- **Google Fonts** — Syne (display) + Space Grotesk (body)
- **Web3Forms** — Contact form submissions (no backend needed)

---

## Features

- Custom animated cursor with hover expansion
- GSAP hero entrance timeline
- Scroll-triggered reveal animations on all sections
- Animated skill progress bars
- Hero stat counter animation
- Horizontal marquee ticker (pauses on hover)
- Magnetic tilt effect on metric cards
- Active nav link highlight on scroll
- Mobile hamburger menu overlay
- Responsive across all screen sizes
- Contact form with Web3Forms API

## Run Locally

No build step needed — pure HTML/CSS/JS.

```bash
git clone https://github.com/manikkori/personalPortfolio.git
cd personalPortfolio
# Open index.html in browser directly
# OR use Live Server in VS Code
```

---

## Deployment

Deployed on **Vercel** via GitHub integration.

Every push to `main` triggers an automatic redeploy.

```bash
git add .
git commit -m "your message"
git push origin main
# Vercel auto-deploys ✓
```
